# ui/ - agent notes

Scope: BOS Studio web app, Svelte 5 + Vite + Tailwind 4, bits-ui, Lucide, TanStack table, Monaco. Owner: svelte-developer. Spec: docs/11_svelte5_ui_studio_and_component_library.md.

## Map
- `src/main.js` mounts `App.svelte`; wraps `fetch` to add the `bos_session` bearer token (auth is moving to bos.core, see reports/cto_proposals_d1_d2_d3_d9.md).
- `src/lib/bos-ui/` (~77 files) design-system components; `src/lib/components/` (~94) app components.
- `src/lib/page-kit/` (~42) runtime for pages generated by crates/bosc-codegen-svelte: contract (createPage, layout components) is defined in that crate's lib.rs header. Change both sides together.
- `src/lib/services/` API clients; `src/api-studio/`, `src/showcase/` extra views.
- `.bos-pages/` is compiled output fetched by the bos-pages-dev Vite plugin (ignored).

## Rules
- Runes only (`$state`, `$derived`, `$props`, `$effect`); no `$:`; no effect mutation loops; clean teardown.
- Real backend data only; responsive (mobile/tablet/desktop); WAI-ARIA; themeable.
- Root ../AGENTS.md rules apply. Search with rg and read ranges; never read node_modules or dist.

## Verify
`npm run build`, `npm run test:page-kit`; visual checks via tester (Playwright).
